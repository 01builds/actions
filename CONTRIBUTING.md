# Contributing to 01builds Actions

Thank you for contributing!

## Development Workflow

1. Clone the repository.
2. Install dependencies: `pnpm install`
3. Make changes in `src/` or `.github/actions/`.
4. Run typecheck and tests: `pnpm run typecheck && pnpm test`
5. Compile action bundle: `pnpm run build`
6. Commit changes (including `dist/index.js`) and open a Pull Request.
